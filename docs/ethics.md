# Ethics & export posture

ZeroMiss is an **educational physics simulator about the universal mathematics of
pursuit** — the same proportional-navigation principle taught in undergraduate courses
and visible in falcons, outfielders, and the sailor's collision rule. It is built to be
unambiguously appropriate to publish.

- **Public-domain math only** — proportional navigation, ZEM, and every validation case
  are standard open-literature textbook material (Zarchan; the JHU APL Technical Digest
  survey papers). No controlled or classified sources.
- **Idealized abstractions** — point-mass (3-DOF) kinematics with a single abstract
  "lethal radius." The interceptor is a constant-speed dot that can only turn.
- **Deliberately NOT modeled** — no propulsion/thrust/mass, no warhead/fuze/blast, no
  real seeker or radar hardware, no real platform or threat parameters, no
  countermeasure-defeat techniques, nothing ITAR/EAR-controlled.
- **Defense-relevant, not defense-sensitive** — it covers guidance, estimation, V&V and
  simulation methodology without containing export-controlled technical data.

The canonical statement lives in the repository's
[`ETHICS.md`](https://github.com/IsmailDayah/ZeroMiss/blob/main/ETHICS.md). If you
believe any part crosses one of the lines above, please open an issue — keeping it clean
is a design goal, not an afterthought.
